# Сайт разработчика сайтов и Telegram-ботов

Статический сайт без сборки: HTML + CSS + немного JavaScript.

**Почему не Next.js.** Сайту нужны скорость, надёжная индексация и простота правок. Одностраничный лендинг без базы данных и серверной логики лучше всего работает как обычные файлы: он грузится мгновенно, не требует Node.js на хостинге и публикуется бесплатно. Если позже понадобятся блог или десятки страниц, структуру легко перенести на Next.js или Astro.

## Структура

```
index.html              главная страница (весь текст, цены, портфолио, FAQ)
privacy/index.html      политика конфиденциальности
assets/css/styles.css   стили и цвета (переменные в начале файла)
assets/js/config.js     контакты и модель калькулятора
assets/js/main.js       меню, вкладки, калькулятор, отзывы
assets/favicon.svg      иконка
assets/og-image.png     картинка для превью ссылки (1200×630)
robots.txt, sitemap.xml для поисковиков
scripts/set-domain.py   подстановка вашего домена
```

## Запуск на компьютере

Откройте `index.html` в браузере двойным щелчком. Либо запустите локальный сервер:

```
python3 -m http.server 8000
```

и откройте http://localhost:8000.

## Публикация

1. Подставьте домен: `python3 scripts/set-domain.py ваш-домен.ru`. Скрипт заменит `YOUR-DOMAIN.ru` в canonical, Open Graph, sitemap.xml, robots.txt и микроразметке.
2. Загрузите содержимое папки на любой хостинг:
   - **Cloudflare Pages / Netlify / Vercel**: перетащите папку в панель управления, сборка не нужна.
   - **GitHub Pages**: загрузите файлы в репозиторий и включите Pages.
   - **Обычный хостинг**: скопируйте файлы в `public_html` по FTP.
3. Включите HTTPS (на перечисленных сервисах он включается автоматически).
4. Проверьте сайт на телефоне и через https://pagespeed.web.dev.

## После публикации

- **Яндекс Вебмастер**: добавьте сайт, подтвердите права (мета-тег можно вставить в `<head>` вместо комментария «Подтверждение прав»), укажите `https://ваш-домен.ru/sitemap.xml`.
- **Google Search Console**: то же самое.
- **Аналитика**: вставьте код счётчика Яндекс Метрики или Google Analytics в `<head>` в месте, отмеченном комментарием, и обновите политику конфиденциальности (раздел «Аналитика и cookie»).

## Что где редактировать

| Что | Где |
|---|---|
| Контакты (WhatsApp, Telegram, телефон) | `assets/js/config.js`. В `index.html` те же значения нужны как запасные для работы без JavaScript, поиск по `79245880575` и `t.me/moonlightdom` |
| Цены на карточках и в разделе «Цены» | `index.html`, поиск по «от 10 000 ₽» |
| Параметры калькулятора (типы, функции, цены) | `assets/js/config.js` |
| Цвета и шрифты | переменные `:root` в начале `styles.css` |
| Название бренда (имя) | `Maxim Starodubcev` в `index.html`, `privacy/index.html` и микроразметке |

### Портфолио
Карточки находятся в секции `#portfolio`. Чтобы показать свою роль, в нужной карточке раскомментируйте строку с комментарием «РОЛЬ» и впишите, что именно вы делали. Пока роль не подтверждена, строка скрыта.

### Отзывы
Блок «Отзывы клиентов» скрыт, пока в нём нет ни одной карточки. Шаблон карточки лежит в комментарии над секцией `#reviews`. Добавляйте только настоящие отзывы с разрешения клиентов. Посмотреть пустой блок можно по адресу `/?reviews=preview`.
